# Desk Dock
StandBy-style desk clock + now-playing for Android. Reads whatever music app is playing on the phone.

Build: open this folder in Android Studio and press Run, or push it to GitHub and run the "Build APK" action.
First launch: tap "Allow music access" and switch on Desk Dock.
Swipe left/right to change layout. Night mode hours: top of MainActivity.kt.
